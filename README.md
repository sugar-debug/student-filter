#Student Filter CLI :

A command-line tool to filter student records from a CSV file.

##Features :
- Filter students by age (shows records where age > threshold)
- Filter students by grade (A,B or C)
- Handles missing files and malformed rows gracefully

##How to run :
python filter_students.py

##Sample data :
The repo includes a sample data 'students.csv' to test with.
